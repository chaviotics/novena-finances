# Novena for Relief from Debt

A nine-day Catholic novena web app (St. Joseph, St. Rita of Cascia, St. Jude Thaddeus) for family prayer.
Single self-contained `index.html`; progress, start date and intention are stored only in each phone's localStorage.

- Live: https://novena-finances.netlify.app
- Hosting: Netlify, auto-deploys from `main`. No build step (`netlify.toml`).
- Design: EB Garamond / Cormorant Garamond; light = wine #6E1F2B + gold #94702A on cream; dark = navy #0E1524 + gold.
- Workflow: draft changes in a Claude artifact, push to `main` only when final.
